# BookNook

**BookNook** is a simple online library platform where readers can
explore books, add new books, borrow books for a few days, and return
them when they are finished.

**Live Website:** <https://booknook-mauve-seven.vercel.app/>

## Features

-   **Browse All Books:** Explore the available books in the library.
-   **Add New Books:** Add books to the collection and share them with
    other readers.
-   **Borrow Books:** Borrow a book for a limited number of days.
-   **My Borrowed Books:** View the books you have currently borrowed in
    one place.
-   **Return Books:** Return borrowed books when you are finished with
    them.
-   **Book Details:** View information about books before deciding what
    to read.
-   **Easy-to-Use Interface:** Navigate the library and manage your
    books through a simple, user-friendly experience.

## Project Overview

BookNook brings a small library experience online. Its main goal is to
make it easy for users to discover books and manage a simple borrowing
process:

**Add a book → Borrow a book → Return a book**
